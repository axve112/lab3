贝塞尔曲线
贝塞尔曲线是由一组“控制点”决定的平滑曲线。为了求出曲线上的具体坐标，我们引入一个参数t∈[0,1]。当t
从0连续变化到1时，求出的所有点连在一起就构成了整条曲线。​De Casteljau 算法是一种利用“递归线性插值”来求取坐标的优雅算法。它的核心思想是：假设我们在屏幕上依次点下了 n个控制点 P 0 ,P 1,…,P n−1。​
第一层插值：对于给定的 t，我们将相邻的两个点连线，并在连线上找到比例为t的点。例如，在​P 0和 P 1之间找到点 P 0′=(1−t)P 0+tP 1。对所有的相邻点执行此操作，会得到n-1个新点。​
递归：对这n-1个新点重复上述的线性插值操作，得到n-2个新点……不断重复。​
终止：当最终只插值出一个唯一的点时，这个点就是贝塞尔曲线在参数t处的确切位置。
实验要求：1.编写纯python函数来实现该算法，返回参数t对应的 [x, y] 浮点坐标。
2.编写一个 @ti.kernel 装饰的函数 draw_curve_kernel(n: ti.i32)。​
在这个函数内部，写一个 for i in range(n): 循环。从 curve_points_field 中读取浮点坐标，将其映射为整数像素索引（乘以宽高），并给 pixels 缓冲区对应的位置赋绿色。​
